# DebouncableInput

[`Input`](?path=/docs/ui-core-input--docs) with debouncing layered on top — a controlled or uncontrolled text input that delays firing state updates, avoiding the need to hand-roll a `useDebounce` in every parent component.

## Installation

```tsx
import { DebouncableInput } from '@repo/ui-core';
```

## Features
- Renders `Input` internally, so it looks and behaves exactly like every other text input in the library.
- Natively intercepts `onChange` to delay firing state updates to `onValueChange`.
- Supports standard React 19 `ref` attributes without needing `forwardRef`.
- Perfect for search inputs, data table filtering, or any field where delayed filtering API calls are required.

> **It is `Input` plus debouncing, and nothing else.** Anything that changes how a text input looks belongs in `Input` and arrives here automatically. If you need the appearance without the delay, reach for `Input` directly — there is no second input primitive to choose between.

## Relationship to `Input` and `Search`

| Component | Use it when |
| --- | --- |
| [`Input`](?path=/docs/ui-core-input--docs) | You want a plain text input. |
| `DebouncableInput` | Every keystroke would otherwise trigger something expensive — a network call, a large re-filter. |
| [`Search`](?path=/docs/ui-core-search--docs) | You want a search field: `DebouncableInput` plus a search icon and an optional clear button. |

## Guidelines & Use Cases

### When to use `DebouncableInput`
- **Search fields**: When typing into an input triggers an API call or expensive DOM filtering.
- **Auto-saving forms**: If you need to trigger a save mutation X milliseconds after the user finishes typing.

### Best Practices
- **Do not wrap `DebouncableInput` in another debounce hook**: The component manages its own internal deferral. Hooking it to an external `useDebounce` is redundant.
- **Rely on `onValueChange`**: The standard `onChange` DOM event is still accessible as a pass-through primitive, but you must strictly use `onValueChange={(val: string) => void}` to capture the deferred output correctly.

## Recipes

### Quick Start

```tsx
import { useState } from 'react';
import { DebouncableInput } from '@repo/ui-core';

export function SearchExample() {
  const handleSearch = (searchTerm: string) => {
    // This will only fire 300ms after the user stops typing
    console.log("Searching for:", searchTerm);
  };

  return (
    <DebouncableInput 
      placeholder="Search for something..." 
      onValueChange={handleSearch} 
      debounceMs={300} 
    />
  );
}
```

### Custom Debounce Timing

By default, the debounce delay is `300ms`. You can increase or decrease this via `debounceMs`.

```tsx
<DebouncableInput
  debounceMs={1000}
  placeholder="1 second debounce..."
  onValueChange={handleSearch}
/>
```
