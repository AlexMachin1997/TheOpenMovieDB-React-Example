# Input

A styled text input built on the native `<input>` element. Supports all standard HTML input types with focus-visible ring, file input styling, and `aria-invalid` error states.

## Import

```tsx
import { Input } from '@repo/ui-core';
```

## Guidelines

- **Always pair with a `<Label>`** for accessibility — never use a placeholder as a label substitute.
- Use `aria-invalid="true"` for error states; never rely on colour alone to communicate errors.
- For multi-line input, use `<Textarea>` instead.
- The `file` type gets custom button styling automatically.

> **`Input` is the single native-input styling primitive in the library.** [`DebouncableInput`](?path=/docs/ui-core-debouncableinput--docs) and [`Search`](?path=/docs/ui-core-search--docs) both compose it rather than restyling an `<input>` of their own, so a change here reaches all three. Don't add a fourth — extend this one, or compose it.

## Features

- Focus-visible ring with `3px` offset
- File input button styling (`file:` variants)
- Dark mode support (`dark:bg-input/30`)
- Error state via `aria-invalid` with destructive ring
- Selection highlight with primary colour

## Accessibility

`Input` renders a native `<input>`, so it inherits the browser's own keyboard and screen-reader
behaviour. What it does *not* do is name itself — that obligation falls on you.

| Obligation | How |
| --- | --- |
| **Give it an accessible name** | Pair with a `<Label htmlFor>` matching the input's `id`. A `placeholder` is not a label: it disappears on focus and is not reliably announced. |
| **Communicate errors** | Set `aria-invalid="true"`, which triggers the destructive ring. Point `aria-describedby` at the element holding the error text so it is announced, not just seen. |
| **Never rely on colour alone** | The error ring is reinforcement, not the message. Always render the reason in text. |

```tsx
import { Input, Label } from '@repo/ui-core';

<div className="grid gap-3">
	<Label htmlFor="email">Email address</Label>
	<Input id="email" type="email" aria-invalid={!!error} aria-describedby={error ? 'email-error' : undefined} />
	{error ? (
		<p id="email-error" className="text-sm text-destructive">
			{error}
		</p>
	) : null}
</div>;
```

Focus is shown with a 3px `focus-visible` ring — `focus-visible`, so it appears for keyboard users
without ringing on every mouse click. `disabled` inputs are skipped by Tab, as native inputs are.
