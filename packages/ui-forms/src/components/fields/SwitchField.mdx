# Switch field

A toggle bound to a **boolean** form field by name.

Use it for a setting that reads as taking effect immediately.

<Canvas of={Stories.Default} />

## What it composes

| Part                                 | Component                                            | What it gives you                                          |
| ------------------------------------ | ---------------------------------------------------- | ---------------------------------------------------------- |
| The control                          | [`Switch`](?path=/story/ui-core-switch--default)     | The toggle and its states                                  |
| Label, description, error and layout | [`Field`](?path=/docs/ui-core-field--docs)           | The visual and accessible wiring around the control        |
| The binding                          | [`FormField`](?path=/docs/ui-forms-form-field--docs) | Value, change, blur and validation state, resolved by name |

## Usage

```tsx
const schema = z.object({ marketing: z.boolean() });

<Form form={form} className='grid gap-4'>
	<SwitchField name='marketing' label='Email me offers' description='Occasional, never shared.' />
</Form>;
```

## Behaviour

- Toggling writes a boolean straight to the field — there is nothing to wire up.
- Messages appear once the switch has been touched, or as soon as the form is submitted.
- A server error attached to this field clears when the user changes it.

## Accessibility

- Reports the `switch` role, so assistive technology announces "on"/"off" rather than
  "checked"/"unchecked".
- The label is a real `<label>` pointing at the control, so clicking the text toggles it.
- The description is linked by `aria-describedby`.

## Properties

<ArgTypes />

`name` is the only one you always pass. There is **no `form` prop** — it comes from the surrounding
[`Form`](?path=/docs/ui-forms-form--docs), and rendering this without one throws.

## Switch or checkbox?

Choose on meaning, not on looks. A switch says the change applies **now**; a
[checkbox](?path=/docs/ui-forms-fields-checkbox-field--docs) says it applies **on submit**. If your
form has a save button, a checkbox is usually the honest choice.
