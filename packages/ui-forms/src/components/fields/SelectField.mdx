# Select field

A [`Select`](?path=/docs/ui-forms-select--docs) bound to a form field by name.

```tsx
<Form form={form} className='grid gap-4'>
	<SelectField name='country' label='Country' options={countries} placeholder='Choose a country…' />
</Form>
```

<Canvas of={Stories.Default} />

## Properties

<ArgTypes />

Shared with every bound field: `name`, `label`, `description`, `required`, `disabled`, `validators`,
`showErrorsWhen`, `id`. See [`Form`](?path=/docs/ui-forms-form--docs) for how validation and server
errors reach a field, and [`Field`](?path=/docs/ui-core-field--docs) for the labelling and message
layout every one of these renders.

There is **no `form` prop** — it comes from the surrounding `Form`, and rendering this without one
throws.

### `type`

`'single'` (the default) binds a `string`. `'multiple'` binds a `string[]` — make sure the form's
default value matches, or the first render has nothing to select from.

<Canvas of={Stories.Multiple} />

## Labelling

Unlike [`RadioGroupField`](?path=/docs/ui-forms-fields-radio-group-field--docs), this keeps
`nativeLabel` at its default. The trigger is a `<button>`, which is a labelable element, so a native
`<label htmlFor>` genuinely names it — no `aria-labelledby` needed.
