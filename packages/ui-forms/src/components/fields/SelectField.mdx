# Select field

A dropdown bound to a form field by name, for choosing from a known list.

<Canvas of={Stories.Default} />

## What it composes

| Part                                 | Component                                            | What it gives you                                          |
| ------------------------------------ | ---------------------------------------------------- | ---------------------------------------------------------- |
| The control                          | [`Select`](?path=/docs/ui-forms-select--docs)        | The trigger, popover, search and option list               |
| Label, description, error and layout | [`Field`](?path=/docs/ui-core-field--docs)           | The visual and accessible wiring around the control        |
| The binding                          | [`FormField`](?path=/docs/ui-forms-form-field--docs) | Value, change, blur and validation state, resolved by name |

## Usage

```tsx
const countries = [
	{ id: 'gb', value: 'gb', label: 'United Kingdom' },
	{ id: 'ie', value: 'ie', label: 'Ireland' }
];

const schema = z.object({ country: z.string().min(1, 'Choose a country.') });

<Form form={form} className='grid gap-4'>
	<SelectField
		name='country'
		label='Country'
		options={countries}
		placeholder='Choose a country…'
		required
	/>
</Form>;
```

## Behaviour

- `type='single'` (the default) binds a `string`. `type='multiple'` binds a `string[]` — match your
  form's default value to whichever you use, or the first render has nothing to select from.
- Messages appear once a choice has been made, or as soon as the form is submitted.
- A server error attached to this field clears when the user changes the selection.

## Accessibility

- The trigger is a `<button>`, which a real `<label>` can name — so clicking the label opens the
  select, and the accessible name is your field label rather than anything generic.
- The message region is linked by `aria-describedby`.
- The popover manages its own focus and closes on `Escape`. See
  [`Select`](?path=/docs/ui-forms-select--docs) for the full keyboard model.

## Properties

<ArgTypes />

`name` is the only one you always pass. There is **no `form` prop** — it comes from the surrounding
[`Form`](?path=/docs/ui-forms-form--docs), and rendering this without one throws.
