# Textarea field

A [`Textarea`](?path=/docs/ui-core-textarea--docs) bound to a form field by name.

Identical to [`TextField`](?path=/docs/ui-forms-fields-text-field--docs) apart from the control it
renders and the `rows` prop. Reach for it when the answer runs to more than one line.

```tsx
<Form form={form} className='grid gap-4'>
	<TextareaField name='bio' label='Short bio' rows={4} />
</Form>
```

## Properties

<Controls />

Shared with every bound field: `name`, `label`, `description`, `required`, `disabled`, `validators`,
`showErrorsWhen`, `id`. See [`Form`](?path=/docs/ui-forms-form--docs) for how validation and server
errors reach a field, and [`Field`](?path=/docs/ui-core-field--docs) for the labelling and message
layout every one of these renders.

There is **no `form` prop** — it comes from the surrounding `Form`, and rendering this without one
throws.

### `rows`

Sets the visible height before scrolling. It does **not** limit what can be typed — use a validator
for that.
